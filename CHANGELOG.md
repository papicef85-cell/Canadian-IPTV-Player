# Changelog

All notable changes to the Canadian IPTV Player project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-24

### Added
- Initial release of Canadian IPTV Player
- 10 legal Canadian specialty networks
  - TSN (Sports)
  - Sportsnet (Sports)
  - CTV Television (General)
  - CBC Television (General)
  - Global TV (General)
  - History TV (Documentary)
  - Discovery Channel (Documentary)
  - Bravo! (Entertainment)
  - Slice (Lifestyle)
  - Showcase (Entertainment)
- Electronic Program Guide (EPG) with historical data (2005-2013)
- Full 24-hour timeline view
- Year-based filtering (2005-2013)
- Date selection for EPG
- Channel search and filtering
- Today's schedule quick view
- Program details panel
- Video player with standard controls
- Responsive design for desktop and mobile
- Real-time channel switching
- HLS/M3U8 stream support
- No external dependencies (pure vanilla JavaScript)

### Documentation
- Complete README with setup instructions
- Contributing guidelines
- API documentation
- Configuration guide
- Troubleshooting section
- License information (MIT)

### Project Structure
- Modular JavaScript architecture
- Clean separation of concerns
- CSS Grid and Flexbox for layout
- Canadian-themed color scheme (red and blue)
- Accessible HTML structure
